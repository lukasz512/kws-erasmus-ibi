# Kaszëbi w Europie! – interactive presentations (Erasmus+ KA122, Ibi 2026)

Organiser start page: `panel.html` (presentations, tools, survey how-to, participant previews).
Presenter: `index.html` (menu: M). Phones: `vote.html` via QR. Languages: `lang.html`. Certificate: `cert.html`.
Live votes go through ntfy.sh (no account, random topic per session). No internet → click answers to count raised hands.
Survey: one module, `survey.js`, used by the presentation and `report.html`; answers are kept in the presenter's browser, the report saves a CSV copy on every open.
Photos: Wikimedia Commons, credits in `credits.js` and on the "Sources" slide.
